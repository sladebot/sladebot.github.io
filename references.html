03Current

Independent research direction

Ongoing work outside any employer. The artifact is orb; the research questions are below.

Current independent research direction

Graph-structured multi-agent LLM runtimes & memory-aware evaluation

My current independent work investigates how multi-agent LLM systems should coordinate, allocate models across roles, persist memory across runs, and expose evaluation telemetry. The goal is to make agentic systems inspectable, reproducible, and measurable — rather than treating multi-agent coordination as only a prompting problem. Orb is the working artifact: a graph-based, multi-tenant, multi-agent coding runtime with daemon, TUI, dashboard, persisted traces, topology selection, per-node model allocation, and a Python SDK.

How should agent graphs preserve and query memory across long-running tasks? When is role-specialized model allocation better than monolithic agents? What does reproducible evaluation look like for multi-agent coding systems?
